# สถิติชี้ช้างศึก U23 โดนเด็กญี่ปุ่น U21 กดมิดด้าม แต่ยังลิ่วรอบ 8 ทีม
หลังจากที่ ทีมชาติไทย ต้านความแข็งแกร่งของเจ้าภาพไม่ไหว พ่ายให้กับ ทีมชาติญี่ปุ่น 0-3 ในศึกฟุตบอลชาย เอเชียนเกมส์ 2026 รอบแบ่งกลุ่ม กลุ่ม เอ นัดสุดท้าย ที่สนามโตโยต้า สเตเดียม เมื่อวันพุธที่ 23 กันยายนที่ผ่านมา แม้จะพ่ายแพ้แต่ทีมชาติไทยยังดีพอที่จะผ่านเข้ารอบต่อไปในฐานะอันดับที่ 2 ของกลุ่ม ด้วยผลงานแข่ง 3 นัด มี 6 คะแนน ขณะที่ญี่ปุ่นคว้าชัย 3 นัดรวด เก็บ 9 คะแนนเต็ม ยิงได้ 12 ประตู และไม่เสียประตูเลยตลอดรอบแรก
ด้านประเด็นหลังเกมสะท้อนให้เห็นถึงช่องว่างมาตรฐานที่ยังห่างชั้นอย่างชัดเจน เมื่อสถิติระบุว่าทีมชาติไทยไม่มีโอกาสง้างเท้ายิงแม้แต่ครั้งเดียวตลอด 90 นาที ที่สำคัญทัพซามูไรบลูส์ชุดนี้ใช้ผู้เล่นรุ่นอายุไม่เกิน 21 ปียกชุด ลงปะทะกับทีมชาติไทยที่ขนผู้เล่นชุดอายุไม่เกิน 23 ปี มาแบบเต็มโควตา ซึ่งแสดงให้เห็นถึงโครงสร้างและศักยภาพเยาวชนที่แตกต่างกันของทั้งสองชาติ
